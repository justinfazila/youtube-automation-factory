## 1️⃣ PILIER 1 : HOOK MASTER (0-30 SECONDES)

### La Formule "PAS" (Problème - Agitation - Solution)

```
PROBLÈME (0-5s)     : Visuel + Audio = Douleur immédiate reconnaissable
AGITATION (5-15s)   : Conséquences + Coût opportunité + Urgence
SOLUTION (15-30s)   : Promesse précise + Preuve visuelle + Roadmap
```

### 5 Templates Hook Validés (Testés A/B)

| Template | Structure | Exemple YT-AF | Exemple LBR | CTR Cible |
|----------|-----------|---------------|-------------|-----------|
| **"Secret Pro"** | "Ce que les [experts] ne disent pas sur [sujet]" | "7 secrets IA que les entrepreneurs cachent" | "Ce que les profs ne te disent pas sur la prise de notes" | 14-18% |
| **"Contre-Intuitif"** | "Arrête de [action commune], fais [alternative] à la place" | "Arrête d'utiliser ChatGPT pour tout, utilise ça" | "Arrête de tout noter en cours, fais ça à la place" | 13-17% |
| **"Preuve Chiffrée"** | "Comment j'ai [résultat mesurable] en [temps] sans [douleur]" | "Comment j'ai gagné 15h/sem avec l'IA en 2 jours" | "Comment j'ai transcrit 3h de cours en 2 min" | 15-20% |
| **"Erreur Coûteuse"** | "L'erreur qui te coûte [X€/Xh] chaque [période]" | "L'erreur qui te coûte 500€/mois en outils IA" | "L'erreur qui te fait rater 50% de tes réunions" | 12-16% |
| **"Démo Immédiate"** | *Visuel pur* : Résultat final → "Comment ? Regarde" | Écran : Dashboard revenus → "Comment ?" | Écran : Transcription propre → "Comment ?" | 16-22% |

### Checklist Hook (Validation Pré-Production)
- [ ] **Visuel au premier plan** (pas de "bonjour, bienvenue")
- [ ] **Promesse quantifiée** (temps, argent, % gain)
- [ ] **Curiosité gap** (ouvre une boucle non fermée)
- [ ] **Identification audience** ("Tu passes 3h à..." = "C'est MOI")
- [ ] **Roadmap visuelle** (3 étapes montrées en rapide)
- [ ] **Durée ≤ 30s** (idéal 22-25s)

## 2️⃣ PILIER 2 : STRUCTURE NARRATIVE - TENSION & RÉSOLUTION

### Modèle "HERO'S JOURNEY" Compressé (8-10 min)

```
MINUTE 0:00-0:30   → HOOK (Problème + Promesse + Preuve)
MINUTE 0:30-1:30   → CONTEXTE RAPIDE (Pourquoi ça marche, autorité)
MINUTE 1:30-3:30   → ÉTAPE 1 : Foundation/Setup (Actionnable)
MINUTE 3:30-5:30   → ÉTAPE 2 : Cœur de la solution (Démo live)
MINUTE 5:30-7:00   → ÉTAPE 3 : Optimisation/Edge cases (Pro tips)
MINUTE 7:00-8:30   → CAS PRATIQUE RÉEL (Preuve sociale + Résultat)
MINUTE 8:30-9:30   → SYNTHÈSE + CHECKLIST + CTA (Lead Magnet)
MINUTE 9:30-10:00  → OUTRO + TEASER PROCHAINE VIDÉO
```

### Techniques de Tension Narrative

| Technique | Application | Fréquence | Exemple |
|-----------|-------------|-----------|---------|
| **Open Loops** | "Je te montre ça dans 2 minutes" | 3-4/vidéo | "Le raccourci clavier ? À 4:30" |
| **Progressive Disclosure** | Infos simples → complexes | Continu | Base → Intermédiaire → Avancé |
| **Stakes Raising** | "Si tu rates ça, tu perds X" | 2/vidéo | "Sans ce paramètre, tes données partent dans le cloud" |
| **Micro-Cliffhangers** | Fin de segment = question | Tous les 2-3 min | "Mais il y a un problème..." |
| **Callback/Récompense** | Référence au hook initial | 2-3/vidéo | "Tu te souviens des 3h de cours ? Voilà le résultat" |

### Structure par Type de Vidéo

#### Type A : Tutoriel Technique (LBR + YT-AF)
```
Hook → Prérequis (30s) → Installation (2min) → Config clé (2min) 
→ Démo complète (3min) → Erreurs fréquentes (1min) → Workflow pro (1min) → CTA
```

#### Type B : Stratégie/Business (YT-AF)
```
Hook → Cadre mental (1min) → Étapes actionnables (3×2min) 
→ Étude de cas chiffrée (2min) → Pièges à éviter (1min) → Ressources (30s) → CTA
```

#### Type C : Comparatif/Outils (Les 2)
```
Hook → Critères décision (1min) → Outil 1 (2min) → Outil 2 (2min) 
→ Verdict + Recommandation par profil (2min) → Migration guide (1min) → CTA
```

## 3️⃣ PILIER 3 : DENSITÉ VALEUR - ZERO FLUFF

### Règle d'Or : **1 Insight Actionnable par Minute Minimum**

| Métrique | Cible | Mesure |
|----------|-------|--------|
| **Insights/Minute** | ≥ 1.0 | Comptage manuel script |
| **Ratio Démo/Parole** | ≥ 60% démo | Timeline montage |
| **Mots "Euh/Donc/Bref"** | < 5/vidéo | Transcription Whisper |
| **Répétitions inutiles** | 0 | Relecture script |
| **Temps "Mort" (chargement, attente)** | Coupé au montage | Jump cuts + time-lapse |

### Techniques Densification

| Technique | Description | Gain Temps |
|-----------|-------------|------------|
| **Jump Cuts Systématiques** | Coupe silences > 0.5s, hésitations | -15-20% durée |
| **Time-lapse Processus** | Installation, téléchargement, rendu | -40-60% segments longs |
| **Picture-in-Picture** | Visage + Écran simultané | +Infos sans temps |
| **Annotations Dynamiques** | Texte clé + Flèches + Surbrillance | Compréhension x2 |
| **Chapitres Cliquables** | Navigation non-linéaire | Rétention +15% |

### Script Template "Densité Maximale"

```markdown
# SCRIPT VIDÉO [TITRE] - Durée Cible: X min

## HOOK (0:00-0:25) - 130 mots max
[Visuel: Problème] → [Audio: Douleur] → [Visuel: Solution] → [Audio: Promesse + Roadmap]

## SEGMENT 1: FOUNDATION (0:25-1:30) - 1 insight/min
[Concept clé 1] → [Démo 30s] → [Piège 1] → [Astuce pro]
→ TRANSITION: "Mais ça ne suffit pas, il faut..."

## SEGMENT 2: CŒUR (1:30-4:30) - 1.5 insight/min
[Action 1] → [Résultat visuel] → [Action 2] → [Résultat visuel]
→ [Cas edge] → [Solution]
→ TRANSITION: "Là où 90% échouent..."

## SEGMENT 3: MASTERY (4:30-7:00) - 1 insight/min
[Optimisation 1] → [Automatisation] → [Intégration workflow]
→ [Raccourci "Bon Raccourci"] → [Gain temps chiffré]

## PREUVE SOCIALE (7:00-8:30) - 1 case study
[Contexte] → [Application] → [Résultat mesurable] → [Témoignage visuel]

## SYNTHÈSE + CTA (8:30-9:30)
[Checklist 3 points] → [Lead Magnet] → [Action précise] → [Teaser V+1]
```

## 🎨 OPTIMISATIONS VISUELLES & AUDIO (Rétention Sensorielle)

### Visuel : Règle "Changement Toutes les 3-5 Secondes"

| Élément | Fréquence | Exécution |
|---------|-----------|-----------|
| **Cut / Changement plan** | 3-5s | Jump cut, zoom, pan, annotation |
| **Texte à l'écran** | Permanent | Mots-clés, chiffres, étapes |
| **Zoom sur action** | Chaque clic important | Ken Burns / Crop dynamique |
| **Progress Bar** | Continu (bas) | "Étape 2/4 - Configuration" |
| **Face Cam (si utilisé)** | Réactions clés seulement | Surprise, validation, "regarde ça" |

### Audio : Design Sonore Rétention

| Son | Moment | Durée | Effet |
|-----|--------|-------|-------|
| **"Whoosh" transition** | Changement segment | 0.3s | Signale progression |
| **"Ding" validation** | Action réussie | 0.2s | Récompense dopamine |
| **"Error" buzzer doux** | Piège évité | 0.3s | Tension → Soulagement |
| **Musique de fond** | Continu (bas -18dB) | Toute vidéo | Cohérence, pace |
| **Silence stratégique** | Avant révélation clé | 0.5-1s | Anticipation max |

| **T6** | Chapitres | Sans vs Avec vs Interactifs | Navigation / Rétention | 14 jours | 2,000 vues |

### Protocole Test Rigoureux

```
1. HYPOTHÈSE CLAIRE : "Jump cuts -20% silence → +5% AVD"
2. ÉCHANTILLON : Random 50/50 sur nouvelles vues (pas abonnés seulement)
3. DURÉE : Min 7j / Max 21j (éviter effet nouveauté)
4. MÉTRIQUE PRINCIPALE : Une seule (AVD ou Rétention 50%)
5. SIGNIFICATIVE : p < 0.05 + effet pratique > 2%
6. DOCUMENTATION : Résultats → Base connaissance → Nouveau standard
```
