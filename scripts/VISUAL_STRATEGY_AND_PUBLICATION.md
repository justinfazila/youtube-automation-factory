# 🎨 STRATÉGIE VISUELLE & PUBLICATION (CANVA, CALENDAR, GITHUB)

Ce fichier définit les prompts pour le Designer et les workflows d'automatisation pour le Lead.

---

## 1. STRATÉGIE DE MINIATURE (CTR > 10%)

**Objectif** : Créer un contraste maximal pour mobile.
**Format** : 1280x720 pixels (JPEG / PNG HD).

### PROMPT DE DESIGN CANVA (Miniature Vidéo 1)
> "High contrast visual for YouTube thumbnail. Left side: Professional entrepreneur character with surprised expression looking at a glowing holographic AI interface. Right side: Large yellow text '7 SECRETS IA' with bold black outline. Background: Dark blue gradient with subtle digital circuit lines. Ultra-HD, vibrant colors."

### Conseils pour le Designer :
*   **Visages** : Émotions fortes indispensables.
*   **Texte** : Maximum 3-4 mots. Police sans-serif très grasse (ex: Montserrat Black ou Anton).
*   **Saturation** : Augmenter la saturation des couleurs principales (Jaune #FFD700, Rouge #FF0000).

---

## 2. STRATÉGIE D'AUTOMATISATION (CALENDAR & PUBLICATION)

### Workflow Google Calendar / Outlook
1.  **Calendrier Éditorial** : Chaque vidéo est un événement "Sujet/Titre" dans le calendrier partagé.
2.  **Rappel** : 24h avant, alerte "Production" pour l'Agent Designer. 1h avant la publication, alerte "Final Check" pour l'Agent Lead.

### Workflow GitHub (Gestion des Assets)
Structure du repository :
```
/youtube-automation-factory
  /scripts (Vidéos en .md)
  /assets (Images miniatures .png, logo .svg)
  /data (Base de données des thèmes / mots-clés .json)
```

---

## 3. PROMPT GMAIL / OUTLOOK (Distributeur)
*Pour le Distributor Agent :*
> "Rédige une newsletter d'accompagnement pour la publication de la vidéo 1. Ton : Professionnel, encourageant, orienté valeur. Contient :

> 2. Lien cliquable vers la vidéo.
> 3. Résumé des 7 secrets.
