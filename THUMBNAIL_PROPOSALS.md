## 🛠️ TEMPLATE CANVA - CONFIGURATION OPTIMISÉE

### **Fichier maître : `THUMBNAIL_MASTER.canva`**

| Élément | Spécification | Note |
|---------|---------------|------|
| **Dimensions** | 1280 × 720 px | Standard YT HD |
| **DPI** | 300 | Export print-ready |
| **Marges sécurité** | 80px bords (zone titre YT) | Évite rognage mobile |
| **Calques verrouillés** | Fond, Grille circuit, Zone sécurité | Anti-erreur |
| **Calques éditables** | Personnage, Interface, Texte principal, Accents | Variantes rapides |

### **Styles de texte pré-enregistrés (Text Styles)**

```

  Font: Montserrat Black
  Size: 140pt
```

### **Workflow création variante (2 min par variante)**

1. **Ouvrir** `THUMBNAIL_MASTER.canva`
2. **Dupliquer** la page → Renommer `Var_1`, `Var_2`, `Var_3`
3. **Var 1** : Activer calques "Split_Horizontal" + "Personnage_Gauche" + "Texte_Droite"
4. **Var 2** : Activer calques "Centered_Hero" + "Texte_Arc" + "CTA_Bas"
5. **Var 3** : Activer calques "Split_Diagonal" + "Texte_HG" + "Personnage_BD"
6. **Remplacer** personnage (drag-drop photo/illustration)
7. **Ajuster** texte si titre change (max 3-4 mots)
8. **Exporter** : PNG 300 DPI + JPG 90% qualité (AB test)
